Deploy Shopee Live View Bot ke VPS Cloud Mandiri

Jalankan bot penonton live streaming Shopee 24 jam nonstop di cloud server tanpa membebani laptop Anda. Panduan ini mengulas integrasi domain dari provider berbeda, konfigurasi SFTP FileZilla aman, dan optimalisasi Server-Sent Events (SSE) agar grafik real-time tidak tertahan.

Node.js v22 LTS Native SQLite
PM2 Autorestart 24/7
SSL Gratis Let's Encrypt
Nginx SSE Buffer-Free

🏗️ Topologi Arsitektur Sistem (Beda Provider)

Meskipun domain Anda dibeli di tempat terpisah (contoh: Niagahoster/Domainesia/Cloudflare) dan VPS disewa di tempat lain (contoh: DigitalOcean/Contabo/Hetzner), alur komunikasi data tetap terhubung lancar melalui standar DNS A-Record:

🌐 Provider 1

Domain Registrar

Niagahoster, Domainesia, Cloudflare, Namecheap. Menyediakan nama domain Anda.

⚡ Jembatan

DNS A-Record

Mengarahkan nama domain (misal: bot.anda.com) ke alamat IP Publik VPS.

🛡️ Provider 2

VPS Linux Cloud

DigitalOcean, Contabo, AWS, dll. Menjalankan Nginx (Port 80/443) dengan SSL HTTPS.

🤖 Runtime

Aplikasi Node v22

Berjalan di port 3000 dipantau PM2 dengan database SQLite terenkripsi AES-256-GCM.

1

Hubungkan Domain ke Alamat IP VPS (DNS Setup)

⏱️ Estimasi: 3 Menit • Dashboard Provider Domain

Buka dashboard tempat Anda membeli domain. Buka menu DNS Management atau DNS Zone Editor, lalu tambahkan dua buah A Record yang mengarah ke IP publik VPS Anda:

Tipe Record Host / Name Target / Points to TTL Keterangan
A @ (atau kosongkan) [IP_PUBLIK_VPS_ANDA] 300 / Auto Domain utama (misal: domainanda.com)
A www [IP_PUBLIK_VPS_ANDA] 300 / Auto Subdomain www (misal: www.domainanda.com)
⚠️
Catatan Khusus Pengguna Cloudflare:
Jika domain Anda menggunakan Cloudflare, pastikan status proxy diatur ke DNS Only (Ikon Awan Abu-abu / Grey Cloud) terlebih dahulu saat proses instalasi SSL Certbot. Setelah sertifikat aktif, Anda boleh menyalakan mode Proxied kembali.

Verifikasi propagasi DNS di terminal laptop Anda:

Terminal / Command Prompt Lokal 
ping domainanda.com
2

Masuk via SSH & Pasang Node.js v22 LTS

⏱️ Estimasi: 5 Menit • PowerShell / PuTTY

Buka PowerShell atau Terminal di komputer Anda dan login ke VPS:

Login SSH 
ssh root@IP_PUBLIK_VPS
🛑
PENTING: Wajib Node.js Versi 22.5.0 ke atas!
Aplikasi ini menggunakan driver native node:sqlite (DatabaseSync). Jangan menggunakan Node.js 18 atau 20 bawaan Ubuntu. Gunakan script resmi NodeSource berikut:
Install Dependensi & Node.js 22 LTS 
# 1. Update paket sistem
sudo apt update && sudo apt upgrade -y
sudo apt install -y curl wget git ufw build-essential nginx certbot python3-certbot-nginx

# 2. Pasang repository resmi NodeSource v22.x
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt install -y nodejs

# 3. Pasang PM2 secara global
sudo npm install -g pm2

# 4. Buat folder target aplikasi di VPS
sudo mkdir -p /var/www/shopee-live-bot
sudo chown -R $USER:$USER /var/www/shopee-live-bot

Periksa apakah versi sudah benar dengan mengetik node -v (harus muncul v22.x.x).

3

Upload File Proyek Menggunakan FileZilla (SFTP)

⏱️ Estimasi: 4 Menit • FileZilla Client PC

Buka aplikasi FileZilla di laptop Anda:

  1. Klik menu File > Site Manager (atau Ctrl + S) → Klik New Site.
  2. Pilih Protocol: SFTP - SSH File Transfer Protocol.
  3. Masukkan Host: IP Publik VPS Anda, Port: 22.
  4. Pilih Logon Type: Normal, isi User: root dan Password VPS Anda.
  5. Klik Connect.
⚠️
ATURAN EMAS UPLOAD:
Arahkan panel kanan (Remote site) ke /var/www/shopee-live-bot.
Upload: folder backend, folder frontend, package.json, package-lock.json, ecosystem.config.js, dan .env.example.
JANGAN PERNAH UPLOAD FOLDER node_modules DARI WINDOWS! Modul binary harus di-build langsung di sistem operasi Linux pada langkah berikutnya.
4

Setup Environment (.env) & Install Dependensi Linux

⏱️ Estimasi: 3 Menit • SSH Terminal

Kembali ke jendela SSH Terminal Anda untuk menyiapkan konfigurasi keamanan:

Konfigurasi .env & Install Modul 
# Masuk ke direktori aplikasi di VPS
cd /var/www/shopee-live-bot

# Salin template environment
cp .env.example .env
nano .env
⚡ Generator Kunci Rahasia Cepat (In-Browser Generator)

Klik tombol untuk menghasilkan secret hash 64-karakter acak untuk variabel SESSION_SECRET Anda:

Pastikan isi file .env Anda memuat parameter berikut (simpan dengan Ctrl + O, lalu keluar Ctrl + X):

Isi File .env di VPS 
SESSION_SECRET=masukkan_kunci_acak_64_karakter_di_atas
APP_SECRET_KEY=shopee-live-enterprise-secret-key-32b!
APP_MASTER_PASSWORD=PasswordKuatAnda123!
NODE_ENV=production
PORT=3000

Jalankan instalasi dependensi Linux:

Install Modul Khusus Linux 
npm install --production
5

Jalankan Aplikasi 24/7 Nonstop Menggunakan PM2

⏱️ Estimasi: 2 Menit • Process Daemon

Jalankan aplikasi dengan konfigurasi production ecosystem.config.js yang sudah tersedia di root proyek:

Perintah PM2 Service 
# 1. Jalankan aplikasi via config ecosystem
pm2 start ecosystem.config.js --env production

# 2. Simpan daftar proses aktif
pm2 save

# 3. Buat script startup agar bot otomatis hidup saat server reboot
pm2 startup
💡
Perintah Berguna PM2:
• Pantau log siaran: pm2 logs shopee-live-view-bot
• Cek penggunaan CPU & RAM: pm2 status atau pm2 monit
• Restart aplikasi: pm2 restart shopee-live-view-bot
6

Konfigurasi Nginx (Reverse Proxy & Buffer-Free SSE)

⏱️ Estimasi: 4 Menit • Web Server

Gunakan generator otomatis di bawah ini untuk menghasilkan blok konfigurasi Nginx yang sesuai dengan domain Anda:

⚙️ Generator Konfigurasi Nginx Sesuai Domain Anda
Buat File /etc/nginx/sites-available/shopee-live-bot 
server {
    listen 80;
    server_name domainanda.com www.domainanda.com;

    client_max_body_size 50M;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;

        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # KRUSIAL UNTUK SSE (SERVER-SENT EVENTS) & REALTIME CHARTS
        proxy_buffering off;
        proxy_cache off;
        proxy_read_timeout 86400s;
        proxy_send_timeout 86400s;
    }
}

Aktifkan konfigurasi di terminal:

Aktivasi & Reload Nginx 
sudo ln -s /etc/nginx/sites-available/shopee-live-bot /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
7

Pasang Sertifikat SSL HTTPS Gratis (Certbot Let's Encrypt)

⏱️ Estimasi: 2 Menit • Security SSL

Jalankan Certbot untuk mengamankan koneksi domain Anda dengan enkripsi gembok hijau HTTPS:

Jalankan Certbot 
sudo certbot --nginx -d domainanda.com -d www.domainanda.com
  • Masukkan alamat email Anda untuk notifikasi perpanjangan.
  • Ketik Y untuk menyetujui Ketentuan Layanan.
  • Pilih opsi Redirect agar seluruh pengunjung dialihkan otomatis ke HTTPS.
8

Proteksi Port dengan Firewall (UFW)

⏱️ Estimasi: 2 Menit • Hardening Server

Kunci akses port yang tidak diperlukan agar server Anda terhindar dari pemindaian liar:

Aktifkan Firewall UFW 
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow OpenSSH
sudo ufw allow 'Nginx Full'
sudo ufw --force enable

❓ Pertanyaan & Pemecahan Masalah Umum (FAQ)

1. Muncul error 502 Bad Gateway di browser setelah memasang Nginx ▼
Ini berarti aplikasi Node.js belum aktif di port 3000. Jalankan pm2 status di terminal SSH. Jika berstatus errored atau stopped, periksa penyebabnya dengan mengetik pm2 logs shopee-live-view-bot.
2. Error: Cannot find module 'node:sqlite' ▼
Versi Node.js di server Anda masih di bawah versi 22. Jalankan perintah instalasi NodeSource v22.x pada Langkah 2, lalu ketik node -v untuk memastikan versi telah terpasang dengan benar.
3. Grafik penonton atau terminal log real-time macet saat diakses via domain ▼
Pastikan baris proxy_buffering off; dan proxy_read_timeout 86400s; telah terpasang di file konfigurasi Nginx Anda. Fitur Server-Sent Events (SSE) membutuhkan transmisi paket instan tanpa jeda buffer Nginx.
4. Certbot gagal memverifikasi sertifikat SSL domain ▼
Pastikan propagasi DNS A-Record sudah mengarah ke IP VPS Anda (coba ping domainanda.com). Jika Anda menggunakan Cloudflare, pastikan ikon awan disetel ke DNS Only (Grey Cloud) saat proses registrasi sertifikat berlangsung.
